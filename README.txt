BRAHMRAJ TRADERS WEBSITE
========================

Files:
- index.html: responsive bilingual business website.
- The supplied official logo is embedded in index.html.

Preview:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.

Free publishing option:
- Create a free GitHub account at https://github.com/
- Create a public repository named brahmraj-traders-website.
- Upload index.html.
- Open repository Settings > Pages.
- Select Deploy from a branch, choose main and /(root), then Save.
- GitHub Pages will publish a free URL.
